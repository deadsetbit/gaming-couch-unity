# 0007: Read-only platform metadata with explicit `notdefined` fallback

`gc.platform.json` is dashboard-managed Platform Data, and letting Unity create or repair it would turn the package into a second, conflicting settings store. We decided Unity only reads the file and projects it to game code as a normalized `GCPlatformRuntimeView` (`Runtime/GCPlayOptions.cs`, snapshot-copied per run in `Runtime/GCActiveRunProjection.cs`): missing or invalid metadata never surfaces as null/undefined but as an explicit fallback view whose game key, entry key, and names are the literal string `notdefined`, with `validationState`/`fallbackActive` as the source-of-truth health fields and persistent `gc.metadata.*` warning diagnostics until the file is fixed. This keeps local development unblocked in a visibly degraded state while ownership of any "fix" stays with the DevApp/dashboard, and upload/publish validation treats fallback metadata as blocking.
