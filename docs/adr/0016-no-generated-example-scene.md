# 0016: No generated example scene

The package deliberately ships no generated example scene route: Active Scene Setup (`Editor/GamingCouchActiveSceneSetup.cs`) is the only setup path, applying safe, non-destructive setup to the user's currently active scene — wiring its `GamingCouch` object, making it the first enabled Build Settings scene, and creating or reusing the example Game listener and player prefab references — while Example Assets (`GCGameExample.cs`, `GCPlayerExample.cs`, `GCPlayerExample.prefab` under `Assets/GamingCouch/GCExample`) are generated as editable project files that are never overwritten and carry a header inviting users to move and rename them into their own project. We chose this because setting up the scene the user is actually working in, with assets they own and can grow into their game, avoids a throwaway package-owned scene and keeps terminology narrowed to Active Scene Setup and Example Assets (start-screen PRD, Task 6). Legacy generated-prefab compatibility checks remain only to guard old project assets.
